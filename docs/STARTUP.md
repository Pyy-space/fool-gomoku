## 2. 环境准备（第一次跑才需要）

只有换机器或删除过环境时才需要做这一节。

### 2.1 需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | **Windows 10 / 11** | 项目用了 Win32 API（窗口枚举、截图、鼠标注入），不能跨平台 |
| Python | **3.10 或更高**（开发验证用 3.13.7） | 3.8 及以下跑不了（用了 `list[int]` 等新语法） |
| 依赖 | 见 `requirements.txt` | `start.bat` 会自动检测并安装 |
| 权限 | 普通用户即可 | 无需管理员；但点击其它程序需要那个程序没被提权 |
| 显示缩放 | 100% ~ 150% 都可以 | 代码按物理像素算，不用手动调 |

### 2.2 装依赖（两种方式）

**方式 A：conda 环境（推荐，本机现状）**

本机已经有一个专用环境 `AI_boardroom`：

```bat
conda activate AI_boardroom
pip install -r requirements.txt
```

如果这个环境被删了，可以重建：

```bat
conda create -n AI_boardroom python=3.13 -y
conda activate AI_boardroom
pip install -r requirements.txt
```

> ⚠️ 如果你重建的环境不叫 `AI_boardroom`，要改 `start.bat` 第 15 行左右的
> `set "PY=D:\anaconda3\envs\AI_boardroom\python.exe"`，改成你的 python.exe 路径。
> （或者不用 bat，直接用第 3 节的「方式 C」手动启动。）

**方式 B：系统 Python / 任意虚拟环境**

```bat
cd /d E:\Code_VS2022_Project\shit_Nogo_UI\GomokuAI
pip install -r requirements.txt
```

`start.bat` 在找不到 `AI_boardroom` 时会自动退回用 PATH 里的 `python`。

### 2.3 验证环境是否就绪

```bat
D:\anaconda3\envs\AI_boardroom\python.exe -c "import flask, flask_socketio, numpy, cv2, mss, win32gui; print('OK')"
```

打印 `OK` 就说明可以跑了。打印 `ModuleNotFoundError` 就回到 2.2 装依赖。

## 3. 启动方式（三种任选）

### 方式 A：双击 `start.bat`（最简单）

会自动做四件事：切代码页到 UTF-8 → 找 Python → 检查依赖（缺了自动装）→ 启动服务并打开浏览器。

### 方式 B：命令行跑 bat（想带参数时用）

```bat
cd /d E:\Code_VS2022_Project\shit_Nogo_UI\GomokuAI
start.bat --no-browser --port 5057
```

### 方式 C：直接跑 Python（最可控，推荐调试时用）

```bat
cd /d E:\Code_VS2022_Project\shit_Nogo_UI\GomokuAI
D:\anaconda3\envs\AI_boardroom\python.exe run.py
```

或者先 `conda activate AI_boardroom`，再 `python run.py`。

### 启动参数一览

| 参数 | 默认 | 作用 |
|---|---|---|
| `--port 5057` | `0`（自动挑 5000 起第一个空闲端口） | 指定端口 |
| `--host 0.0.0.0` | `127.0.0.1` | 让同一局域网的手机/另一台电脑也能访问 |
| `--no-browser` | 关 | 不自动弹浏览器 |
| `--debug` | 关 | 打印 Flask 调试日志（排查接口问题用） |

**启动成功的标志**：控制台出现

```
==========================================================
  五子棋 AI 助手
  本地访问: http://127.0.0.1:5000/
  按 Ctrl+C 停止
==========================================================
```

端口不是你期望的那个也没关系 —— 每次启动会从 5000 往上找第一个没被占用的，**以控制台打印的地址为准**。

```
◉ 五子棋 AI  GomokuAI   ‹ 模式     ● 已连接
```

- 右上角**绿点 + 「已连接」** = 前后端 WebSocket 通了，一切正常

## 5. 各页面怎么用

页面结构是三层：落地页 → 模式选择 → 具体功能。

```
/           落地页
/hub        模式选择（人机对弈 / 识别下棋）
  /local    人机对弈（测试功能一）
  /auto     识别下棋（窗口识别自动对战）
  /vision   识别调试（标定 Profile 用）
  /lab      实验室（训练=机器对弈调参，隐藏入口）
```

### 5.1 人机对弈（`/local`）—— 测试功能一

人和 AI 下棋，**不需要任何游戏窗口**，想验证棋力就用这个页面。

| 操作 | 说明 |
|---|---|
| 我执 | 选黑（先手）或白（后手）。选白时 AI 会先走一步 |
| 难度 | 1~5 档。1 是 0.15 秒快棋，5 是 5 秒深思。**默认 3 档（1 秒）已经能碾压大部分游戏 NPC** |
| 棋盘 | 13 / 15 / 19 路。默认 15 路标准盘 |
| 规则 | 无禁手（休闲）/ 连珠（黑方禁长连、四四、三三） |
| 开始新局 | 按当前设置重开 |
| 悔棋 | 一次撤两步（把你和 AI 的应手一起撤掉） |
| 提示一手 | AI 给一个建议点，但**不会落子**，你自己决定下不下 |
| 认输 | 结束当前局 |

点棋盘就落子，AI 在后台思考（页面不会卡），落完子立刻刷新。左侧「AI 分析」会显示它算出的得分、深度、节点数、耗时。

### 5.2 识别下棋（`/auto`）—— 需求 1~3 的闭环

让程序自己看屏幕、自己下棋。**第一次用必须先跑演练模式。**

1. `Profile` 选 `yanyun`（燕云十六声）或 `generic`（通用）
2. 点 **「刷新窗口列表」**，在下拉框里选中你的游戏窗口（显示成 `[句柄] 窗口标题 · 类名`）
3. 我方执色：不确定就留「自动判断」
4. 每步思考：默认 2 秒，够用
5. 稳定帧数：默认 2。如果游戏有落子动画，调到 3~4
6. ☑ **先勾上「演练模式（只算不点）」** → 点「开始」
7. 看右侧「事件」日志和中间的棋盘 —— 确认**识别到的棋子和游戏里看到的一模一样**，并且它算出的落点合理
8. 确认无误 → 停止 → 取消勾选演练模式 → 再点「开始」，它就真的会点鼠标了

状态机：`locating`（找窗口）→ `waiting`（等对手）→ `thinking`（思考）→ `placing`（落子）。卡在哪个阶段，事件日志会说原因。

### 5.3 识别调试（`/vision`）—— 标定 Profile 用

单次截图识别，**调 Profile 只在这个页面调**。

1. 选 Profile、选窗口
2. 点「截图并识别」
3. 看大图：黄色网格线是否贴合棋盘？每个交点的小圆点是否落在真实棋子中心？
4. 看右侧摘要：识别到几颗子、置信度、网格得分、格距
5. 看「盘面」文本：`X` = 黑、`O` = 白、`·` = 空，直接和游戏画面对照

「显示坐标标签」「显示网格」两个勾选框可以帮你判断是网格拟合偏了还是分类错了。

**判断标准**：如果叠加图和真实棋盘完全对齐、识别的子和眼睛看到的一致，`/auto` 就能用；反之先调 profile（见第 7 节）。

### 5.4 实验室（`/lab`）—— 训练=自我对弈调参（测试功能二）

> ⚠️ **隐藏入口**：实验室不在导航里，要靠彩蛋进入 —— 在任意页面**页脚版本号 `v1.0` 上连点 5 次**（1.6 秒内）。
> 进入后还要输入**访问口令**（默认 `gomoku-lab`，可用环境变量 `GOMOKU_LAB_TOKEN` 改）。
> 两层防护：彩蛋负责隐蔽，口令负责真锁。

> 这个页面**不是训练神经网络**。项目里没有神经网络权重。
> 它是让 AI 自己跟自己下几百局，用胜负来**搜索引擎的超参数**（防守权重、搜索宽度等）。

1. 策略选「坐标搜索（稳、慢）」或「SPSA（快、噪声大）」
2. 每组对局数：默认 2（一局 A 执黑 + 一局 A 执白，配对降噪）
3. 迭代轮数：想快点看效果就 2~4 轮；认真调就 8~20 轮
4. 点「开始调参」，进度和当前最优参数会实时显示
5. 结果自动存到 `output/tuning/tune_<策略>_<时间戳>.json`

想快速验证它能不能跑：`每组对局数 = 1`、`迭代轮数 = 1`、`每步限时 = 0.1`，十几秒就出结果。

## 6. 接《燕云十六声》的完整流程

前置：游戏已启动，并进入五子棋小游戏界面（棋盘在画面上可见）。

```
第 1 步  启动 GomokuAI（start.bat）
   ↓
第 2 步  打开 /vision 页面，选 yanyun profile
   ↓
第 3 步  选窗口：点「刷新窗口列表」，找标题含「燕云十六声」的那一项
        （找不到？见 8.3；游戏可能是无边框全屏，标题会显示成 yysls）
   ↓
第 4 步  点「截图并识别」
   ↓
        ┌── 叠加图和棋盘对齐、棋子数对了 ──→ 进第 5 步
        └── 网格偏了 / 识别成一片空 ──────→ 见 8.4 调 Profile，调好再回来
   ↓
第 5 步  打开 /auto，选同一个窗口
        勾「演练模式」，点「开始」
   ↓
第 6 步  看事件日志：应该出现「已锁定窗口」「识别到 N 个新子」
        看中间棋盘：和游戏画面一致
   ↓
第 7 步  停止 → 取消「演练模式」→ 再点「开始」
        现在它会真的点击游戏窗口落子
```

**执色说明**：程序会数盘面上黑白子的数量来推断轮到谁。如果你发现它一直「等待对手」，多半是执色判断反了 —— 在 `/auto` 的「我方执色」里手动选黑或白。

**重要提醒**：
- 点击落子需要游戏窗口**在前台**（Windows 输入机制限制）。所以别一边切别的窗口一边跑。
- 第一次跑建议把「每步思考」设成 3~4 秒，先保证想清楚而不是快。
- 如果游戏有落子动画/特效，把「稳定帧数」调大（3~5），否则会把动画中的画面当成新落子。

## 7. 接任意其它游戏/网页

**核心机制：新增一个目标程序 = 在 `profiles/` 里新增一个 JSON 文件，不改一行代码。**

### 7.1 复制模板

复制 `profiles/generic.json`，改名为你的游戏，比如 `profiles/qq_wuziqi.json`。

### 7.2 最少要改的字段

```jsonc
{
  "name": "qq_wuziqi",
  "description": "QQ 游戏五子棋",
  "window": {
    "title_regex": "五子棋|QQ游戏"      // ← 窗口标题正则，用 | 分隔多个候选
  },
  "board": {
    "size": 15,                          // ← 棋盘几路
    "auto": true,                        // 先留 true，自动检测
    "roi": [0.05, 0.05, 0.95, 0.95]      // ← 只在这个相对区域找棋盘
  }
}
```

其余字段全部保持默认即可。

### 7.3 通用性怎么保证的

程序**不写死任何界面坐标**：

- 棋盘位置靠**图像检测**（行/列投影取峰 → 稳健最小二乘拟合），不是硬编码像素
- 棋子判空靠**结构特征**（空交点有网格线穿过，棋子是实心圆），与配色无关，白子配浅色盘、黑子配深色盘都能识别
- 黑白靠**相对明暗聚类**，不需要预先知道双方颜色

所以同一个 profile 通常能扛住窗口大小变化、不同的棋盘皮肤。

### 7.4 什么时候需要手动标定

| 情况 | 处理 |
|---|---|
| 2D 正视角棋盘 | `auto: true` 就够了 |
| 画面有缩放/裁切 | 收窄 `roi` |
| 3D 斜视角（透视变形） | 必须用 `quad` 四点标定，`auto` 不行 |
| 自动检测老是偏一格 | 手动给 `origin`（左上第一个交点像素坐标）+ `spacing`（格距像素） |
| 镜像视角（黑白左右反） | `axis` 改成 `flipped_x` / `flipped_y` / `flipped_xy` |

### 7.5 截图方式

`capture.method` 三个选项：

| 值 | 什么时候用 |
|---|---|
| `printwindow` | **首选**。让窗口自己重绘一遍，前台被别的程序挡着也能截到 |
| `screen` | PrintWindow 拿到纯色/黑图时。**要求窗口在前台且没被遮挡** |
| `auto` | 默认。先试 PrintWindow，整张图几乎纯色才退回 screen |

> 实测教训：前台全屏跑着别的游戏时，`screen` 截到的是那个前台游戏的画面。真实游戏窗口请用 `printwindow`。

## 8. 常见问题排查

### 8.1 双击 start.bat 一闪就没了

用命令行跑，才能看到错误：

```bat
cd /d E:\Code_VS2022_Project\shit_Nogo_UI\GomokuAI
start.bat
```

看最后几行提示。最常见是 Python 路径不对（改 bat 里的 `PY=` 那行）。

### 8.2 浏览器打开了但显示「无法访问此网站」

1. 看控制台有没有真的打印出 `本地访问: http://127.0.0.1:xxxx/`
2. 有的话，**地址里的端口可能不是 5000** —— 端口被占用时程序会自己往上找。照控制台打印的地址手动输一次
3. 控制台报 `Address already in use` 之类的，用 `--port` 指定一个明确的空闲端口

### 8.3 刷新窗口列表，找不到游戏窗口

- 游戏是不是**最小化**了？最小化的窗口截不到图，先恢复
- 游戏是不是**无边框全屏**？这种模式下标题可能变成进程名（如 `yysls`），在列表里翻一下
- 仍然找不到 → 用 `generic` profile（它不按标题过滤），然后在列表里手动点选
- 想确认程序到底枚举到了哪些窗口：控制台跑

  ```bat
  python -c "from core.window import list_windows; [print(w) for w in list_windows()]"
  ```

### 8.4 识别不准（`/vision` 页面）

按这个顺序排查：

| 现象 | 原因 | 处理 |
|---|---|---|
| 报「网格识别失败」 | 画面里没有清晰的等距网格线 | 收窄 `roi` 到棋盘区域；或手动给 `origin`+`spacing` |
| 网格线明显偏了一格 / 偏几个像素 | 自动拟合被干扰 | 手动给 `origin` 和 `spacing`（先用截图工具量一下） |
| 棋子数对了但位置镜像 | 视角左右/上下反了 | `axis` 改成 `flipped_x` / `flipped_y` / `flipped_xy` |
| 空点被大量误判成棋子 | 阈值被噪声带偏 | 把 `roi` 收窄，去掉界面边框/文字 |
| 有子被漏判 | 棋盘被遮挡 / 动画中 | 把 `stable_frames` 调大；确认截图时棋盘完全可见 |
| 网格得分很低（< 0.4） | 棋盘线被棋子盖住太多 | 真实对局很少到满盘；如果经常出现，换 `printwindow` 方式试试 |

### 8.5 自动对战一直「等待对手」

程序认为还没轮到自己。原因通常是执色判断反了：

- 在 `/auto` 页面把「我方执色」从「自动判断」改成明确的「黑」或「白」
- 再确认一次 `/vision` 里识别的黑白是否和你眼睛看到的一致（如果黑白反了，`axis` 或颜色聚类有问题）

### 8.6 自动对战「思考」了但没落子 / 点歪了

- 先确认演练模式下 `/auto` 中间那个棋盘上，落点标记位置是对的
- 如果落点整体偏了一点：调 `input.offset`（点击点微调，单位像素）
- 如果完全没反应：游戏窗口可能不在前台，或游戏以管理员权限运行而本程序没有（权限不对等时 Windows 会丢弃模拟输入）

### 8.7 改代码后页面没变化

**Flask 没开热重载。改任何后端 `.py` 都必须重启 `run.py`。**

前端文件（`app/static/*.js`、`*.css`、`app/templates/*.html`）刷新浏览器即可，但有缓存的话按 `Ctrl+F5` 强制刷新。

### 8.8 控制台中文乱码

`start.bat` 里已经做了两件事解决这个：`chcp 65001` + `PYTHONIOENCODING=utf-8`。如果你是手动跑 `python run.py`，先执行：

```bat
set PYTHONIOENCODING=utf-8
chcp 65001
```

## 9. 关闭与再次启动

### 关闭

在运行 `start.bat` 的那个命令行窗口按 **`Ctrl+C`**，出现 `Press CTRL+C to stop` 后确认即可。
如果窗口直接关掉了，后台进程也会一起结束（没有常驻服务/开机自启）。

### 再次启动

每次都是同样的操作，**直接再双击 `start.bat` 就行**，不需要任何清理步骤。

已经下过的棋、调参结果都不会丢：
- 调参结果在 `output/tuning/`
- 截图在 `output/shots/`

### 想让局域网里别的设备也能访问

```bat
start.bat --host 0.0.0.0
```

控制台会多打印一行 `局域网: http://192.168.x.x:端口/`，手机连同一个 WiFi 就能打开下棋（只是打开界面，识别和点击仍然在本机执行）。
